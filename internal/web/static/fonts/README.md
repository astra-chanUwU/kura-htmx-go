# Atkinson Hyperlegible

Original Atkinson Hyperlegible, regular (400) and bold (700), self-hosted in WOFF2 format. Both weights are embedded into the Kura binary with the other static assets. No font CDN is used.

Source: https://github.com/googlefonts/atkinson-hyperlegible/tree/main/fonts/webfonts
License: SIL Open Font License 1.1, included in OFL.txt.

Palette reference: https://github.com/monkeytypegame/monkeytype/blob/master/frontend/src/ts/constants/themes.ts (`magic_girl` and `dark_magic_girl`). The core palette colors are preserved; supporting text colors are adjusted for readable archive UI contrast.
